Version and scope

The protocol identifier is aether/v1 and the Schema version is 1.0.0. This repository maintains the Schema and field reference.

The Schema describes document structure. A field appearing in the Schema does not imply that every runtime implements its behavior.

This repository currently provides structural definitions and a field reference. Complete execution semantics and conformance cases have not yet been documented. Check the reference implementation for runtime support.
