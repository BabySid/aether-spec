# Aether Protocol

Schema and reference documentation for the Graph Workflow Protocol (`aether/v1`).

- [HTML documentation](index.html): clone the repository and open this file in a browser.
- [HTML schema reference](docs/schema.html): browse and search fields by type.
- [JSON Schema](schema/v1/graph-schema.json): machine-readable structural definitions.
- [Go reference implementation](https://github.com/BabySid/aether).

Documentation works offline with no dependencies or build step. GitHub file pages display HTML source; a hosted documentation site is not configured.

The protocol identifier is `aether/v1` and the Schema version is `1.0.0`. Protocol declarations and implementation support must be checked separately.
